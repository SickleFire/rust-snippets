# Async & Ecosystem Rust Lab

A bite-sized conceptual reference notes and code patterns repository for asynchronous Rust and key ecosystem crates.

## Covered Topics

- **Tokio & Async**: Runtimes, task spawning (`tokio::spawn`), timers (`tokio::time`), synchronization channels (`tokio::sync`), and concurrency joining (`tokio::join!`).
- **Reqwest**: HTTP clients (`reqwest::Client`), simple GET requests, JSON deserialization, and POST requests with payloads.
- **Serde**: Derive macros (`Serialize`, `Deserialize`), field renaming (`camelCase`), optional fields/defaults, and flattening/custom serialization.

## Repository Structure

- `index.html`: Interactive single-page web reference lab containing all lessons, code snippets, and tab navigation.

## Usage

Open `index.html` in any web browser to explore the interactive reference notes and copy code patterns.
